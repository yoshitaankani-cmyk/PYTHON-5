# Repeated Transaction Detection

## About the Project
The Repeated Transaction Detection system is designed to analyse transaction records and identify duplicate transaction IDs and high-value transactions.

## Objectives
- Accept multiple transaction records.
- Store transaction IDs and amounts.
- Detect duplicate transaction IDs.
- Identify transactions exceeding a specified amount.
- Display suspicious transaction details.

## Concepts Used
- Variables and data types
- Lists
- Nested loops
- Conditional statements
- String operations

## How the Program Works
1. The user enters the number of transactions.
2. Transaction IDs and amounts are collected.
3. The details are stored in separate lists.
4. Nested loops compare transaction IDs.
5. Duplicate transaction IDs are identified.
6. Transactions exceeding ₹10,000 are displayed as high-value transactions.
7. A transaction report is generated.

## Conclusion
This project demonstrates how Python lists and nested loops can be used to identify duplicate and high-value transactions.
